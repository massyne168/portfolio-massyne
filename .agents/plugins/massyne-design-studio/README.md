# MASSYNE Design Studio — Antigravity Plugin

A specialist AI design studio plugin for the **MASSYNE portfolio project**
(`S:\Projects\portfolio-massyne`). Provides premium UI/UX, mobile-first
responsive design, cinematic aesthetic enforcement, and motion design expertise
scoped to the MASSYNE codebase.

---

## What's Included

| Component | File | Purpose |
|---|---|---|
| Plugin manifest | `plugin.json` | Plugin metadata and suggested prompts |
| Design rules | `rules/AGENTS.md` | Always-on design constraints |
| UI/UX Skill | `skills/massyne-uiux-design/SKILL.md` | Full design system, protocols, and checklists |
| UI/UX Agent | `agents/uiux-design-agent.md` | Senior design reviewer and implementer |
| Mobile Agent | `agents/mobile-responsive-agent.md` | Mobile layout specialist |
| Creative Director | `agents/creative-director-agent.md` | Brand standard and creative direction |

---

## Design Principles

- **Dark. Sharp. Purposeful.** — Every decision serves the MASSYNE brand.
- **Mobile is first-class.** — Never "scaled down from desktop."
- **Motion earns its place.** — Cinematic, not decorative.
- **Inspect before changing.** — Read the code, trace the references, then propose.

## Rules Summary

1. Inspect before changing.
2. MASSYNE aesthetic is inviolable.
3. Mobile is a first-class citizen.
4. The 9-section panel system must be preserved.
5. `mobile-nav.css` must be linked in `index.html`.
6. Git operations require explicit owner approval.
7. Vercel deployment requires explicit owner approval.
8. Asset protection — no deletion or renaming without approval.
9. `AGENTS.md` is read-only.
10. No external dependencies.
11. Scope discipline.
12. Transparent reporting.
