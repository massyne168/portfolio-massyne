PUBLISH / GITHUB

Keep GitHub connected.

Studio publishes through a private Vercel server connection. The GitHub token stays on the server and is never sent to this browser.

  1. Create a fine-grained token on GitHub ↗.
  2. Limit it to Only select repositories → portfolio-massyne.
  3. Grant Contents: Read and write. No other permissions are needed.
  4. In Vercel, add it as a Production Secret named MASSYNE_STUDIO_GITHUB_TOKEN, then redeploy.
